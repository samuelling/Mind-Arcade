Adaptive Neuropsych Battery

Eleven short tasks, one Bayesian engine, and generative models for memory, fluency and mental rotation. Each next test is chosen by expected information gain while many patterns are live, then by how well it splits the top two once the field narrows. The session stops only when the leader is above 90% and two independent tests each favor it. Play the arcade version.

Takes 8 to 15 minutes. A keyboard works best; touch is supported.

    How the engine decides

    Generative task models

    Word list, fluency and rotation are fit at the trial level. Memory: storage after n studies is 1 − (1 − e)ⁿ, recall is storage × access r, storage decays as e−fD, and recognition follows a two-high-threshold rule. Fluency: entries form a Poisson process that depletes a pool of N items with time constant τ. Rotation: RT = non-decision + angle / rotation rate + a Wiener diffusion with drift v and boundary a.

    Patterns in parameter space

    Eight patterns each predict a z-score for every parameter and every classic score, with spread σ = 0.7. For model tests, each pattern is scored by its exact marginal likelihood: the data likelihood integrated over the whole fitted grid under that pattern's parameter distribution. Correlated parameters (encoding vs access) are handled jointly.

    Explore and exploit

    Expected information gain over all patterns (explore) is blended with the expected log-likelihood ratio between the top two (exploit). The weight is w = (2^H − 1) / 7, and utility is divided by test minutes. Planning uses each model's typical posterior precision, so tests that fit noisily are valued less.

    Predictions

    Before every test, the engine commits to an 80% predictive band for each measure from the current pattern mixture. After list learning, it also predicts delayed recall and recognition mechanistically, by importance sampling memory parameters conditioned on the learning curve. The ledger scores every prediction.

    Triangulation

    Each completed test is a sightline. It converges when its own evidence favors the leader over the runner-up by BF ≥ 3. For delayed recall, only the evidence the delay added counts, so learning trials are never double-counted.

    Stopping

    Converged: P ≥ 0.90 with two converging tests. Single-line: P ≥ 0.97 with nothing left that separates the top two. Unresolved: battery exhausted. Norms and pattern means are placeholders, built to be replaced by fits to ADNI, NACC or new data.
